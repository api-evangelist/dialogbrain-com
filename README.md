DialogBrain provides an AI-powered customer communication platform that integrates with WhatsApp, Telegram, Instagram, email, and voice calls. It offers a unified inbox where businesses can manage inquiries across multiple channels, automate replies with customizable rules, and approve messages before they are sent. The service includes a no‑code setup, pricing plans for various business sizes, and tools for sales, support, and appointment scheduling, all accessible via web and mobile apps.

**Areas:** Company · AI · Customer Support · Messaging · Voice

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for dialogbrain-com: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
